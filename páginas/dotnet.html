Introdução ao .NET

O .NET é uma plataforma de desenvolvimento free, cross-platform e open-source da Microsoft. Ela permite criar aplicações web, APIs, aplicativos desktop, mobile e muito mais.

O que é importante saber

  • .NET é a plataforma; o runtime atual é o .NET 5/6/7/8+ (verificar a versão mais recente).
  • C# é a linguagem mais comum no ecossistema .NET, mas também existem F# e VB.NET.
  • O SDK inclui o dotnet CLI para criar, compilar e executar projetos.

Instalação rápida

Instale o SDK do .NET seguindo as instruções em dotnet.microsoft.com. Em sistemas Linux muitas vezes existe um pacote oficial ou instruções com script.

Comandos iniciais

Exemplos usando a CLI dotnet:

dotnet new console -o HelloWorld      # cria um app console
cd HelloWorld
dotnet run                            # compila e executa
dotnet build                          # somente compila
dotnet new webapi -o MinhaApi         # cria uma API web básica
